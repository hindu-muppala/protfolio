# Hindu Muppala Portfolio

A responsive, GitHub Pages-ready portfolio website for Hindu Muppala, focused on Junior NLP Engineer and Generative AI Engineer roles.

## Files

- `index.html` - Page structure, SEO tags, sections, and portfolio content.
- `style.css` - Responsive dark theme, layout, cards, and animations.
- `script.js` - Mobile navigation, scroll reveal, active navigation, current year, and animated hero background.

## Sections Included

- Hero section with Open to Work banner
- Target roles: Junior NLP Engineer and Generative AI Engineer
- About section
- Skills section
- Featured projects
- Contact section
- Footer

## Featured Projects

- AI Career Counselor
- Finance RAG Chatbot
- Multilingual Health Assistant

- Collaborative Code Editor

## Customize Before Publishing

Open `index.html` and replace these placeholder links:

- `your-email@example.com`
- `https://github.com/your-username`
- `https://www.linkedin.com/in/your-linkedin-profile`
- `https://github.com/your-username/ai-career-counselor`

You can also update project links, project descriptions, and skill badges in the same file.

## Run Locally

No build step is required.

Open `index.html` directly in a browser, or run a local static server from this folder.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to repository `Settings`.
4. Open `Pages`.
5. Set the source to `Deploy from a branch`.
6. Select the `main` branch and `/root`.
7. Save and wait for GitHub to publish the site.

## Notes

- The site uses only HTML, CSS, and vanilla JavaScript.
- There are no external CDN dependencies.
- The layout is responsive for mobile, tablet, and desktop.
- The animated hero background respects reduced-motion preferences.
